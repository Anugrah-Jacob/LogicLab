Half adder

A half adder is a combinational circuit that adds two single bits and produces a sum bit and a carry bit.

Boolean expressions

  • Sum = A ⊕ B

How it works

The sum is 1 when exactly one input is 1, which is an XOR. The carry is 1 only when both inputs are 1, which is an AND. It cannot accept a carry from a previous stage, so it is used for the least significant bit; chains of bits need full adders.
