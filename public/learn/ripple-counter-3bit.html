3-bit ripple counter

A ripple counter is an asynchronous binary counter made from a chain of toggle flip-flops.

Open this circuit in LogicLab →

Boolean expressions

  • Q0 toggles every clock
  • Q1 toggles when Q0 falls
  • Q2 toggles when Q1 falls

How it works

Each flip-flop has T tied to 1, so it toggles whenever its clock input falls. The first stage is clocked by the input clock and every later stage by the output of the stage before it, which halves the frequency at each step. The count therefore runs 0 to 7 and wraps around.

Try it yourself

Three toggle flip-flops, each clocked by the falling edge of the previous stage, count 0 to 7. Open the circuit, click the switches to change the inputs, and watch the LEDs and the waveform panel respond.
